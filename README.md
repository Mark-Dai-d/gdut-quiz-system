# 思政个性化刷题系统（GitHub Pages 公开版）

这是一个可直接部署到 GitHub Pages 的静态刷题系统，内置导论至第十七章共 384 道课后题。

## 在线能力

- 浏览器注册 / 登录
- 多账号本地数据隔离
- 章节专项、全真随机、错题专项、今日复习刷题
- 单选题 / 多选题自动判分
- 错题本、艾宾浩斯复习排期、学习统计
- 错题考点提炼与错题 HTML 导出

## 重要说明

GitHub Pages 只能托管静态网页，不能运行 Python 后端或 SQLite 数据库。因此公开版的数据保存在访问者自己的浏览器 `localStorage` 中：

- 同一浏览器内的账号数据彼此隔离；
- 换设备、换浏览器或清空浏览器数据后，学习记录不会自动同步；
- 静态公开版不适合保存敏感密码，建议只用于个人刷题。

需要真正服务端多用户数据库、管理员题库编辑和全量备份时，请使用本机 Python 后端版。
